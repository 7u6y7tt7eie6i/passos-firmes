# Colégio Passos Firmes

Site institucional do Colégio Passos Firmes — Educação Infantil ao Ensino Médio em Matelândia - PR.

Site estático (HTML, CSS e JavaScript puro), sem dependências. Para ver, basta abrir o `index.html` no navegador.

## Estrutura

- `index.html` — página única com todas as seções
- `css/style.css` — estilos (desktop, tablet e celular)
- `js/main.js` — menu, animações de entrada e efeitos interativos
- `assets/img/` — fotos e imagens

Fotos da seção Diferenciais: banco de imagens gratuito [Pexels](https://www.pexels.com).
